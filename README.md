# Claude Skills Pack

This repository contains reusable Cursor/Claude-style skills for:

- Writing concise, clean code
- Reviewing code for correctness and maintainability
- Finding strong edge-case test scenarios
- Developing human-readable specs with alternative designs

## Skills

- `concise-clean-code`: Produces simple, readable, maintainable code with minimal noise.
- `code-review`: Reviews code changes with prioritized findings and actionable feedback.
- `edge-test-cases`: Generates high-value edge-case tests and risk-focused coverage.
- `spec-development`: Turns problem statements into clear specs with multiple design options and tradeoffs.

Each skill is self-contained in its own folder with a `SKILL.md` file.
